As the new Akafö website does not show the menu plan for the following anymore, this project is implemented.
This project reads the RUB (Mensa, Rote-Beete, QWest) menu data by week (KW<XX>) and 
1. pretty print the results in console output
2. store in local project under `./menu/kw<xx>/`

The next step of this project is to build an GUI for Android phones (possibly with `kivy`).
Or to rewrite this project with JavaScript / TypeScript and build a Vue App for web usage.
